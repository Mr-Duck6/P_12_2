# Movie Catalog - Каталог фільмів

## Основний функціонал
У додатку реалізовано такі можливості:
- Каталог фільмів - відображення списку фільмів у вигляді карток.
- Пошук фільмів - пошук за назвою. Пошук запускається після введення мінімум двох символів.
- Очищення пошуку - кнопка Clear для видалення введеного тексту.
- Індикатор завантаження - відображається під час виконання пошуку.
- Повідомлення No results - показується, якщо за пошуковим запитом нічого не знайдено.
- Картки фільмів - містять постер, назву та рейтинг фільму.
- Заглушка постера - якщо зображення не завантажилося, замість нього відображається іконка.
- Детальна інформація - можливість відкрити окремий екран з інформацією про фільм.
- Обране - можливість додавати фільми до списку улюблених та видаляти їх звідти.
- Рейтинг - відображення рейтингу фільму у вигляді зірок.
- Share - кнопка для демонстрації дії поширення інформації про фільм.

## Опис головних файлів

models/movie.dart
Містить модель фільму Movie. У ній визначені основні поля: ID, назва, опис, посилання на постер, рейтинг, рік випуску, жанр та режисер.

providers/movie_provider.dart
Відповідає за управління станом додатка. У цьому файлі реалізовано список фільмів, пошук, очищення пошуку, перевірку обраного, додавання та видалення фільмів.

widgets/movie_search_bar.dart
Віджет пошукового рядка. Реалізує введення пошукового запиту, кнопку очищення, індикатор завантаження та повідомлення про відсутність результатів.

widgets/movie_grid.dart
Віджет для відображення фільмів у вигляді сітки з двома колонками. Картки містять постер, назву та рейтинг. При натисканні відкривається екран детальної інформації.

screens/home_screen.dart
Головний екран додатка. Містить пошуковий рядок, каталог фільмів та кнопку переходу до обраного.

screens/movie_detail_screen.dart
Екран детальної інформації про вибраний фільм. Відображає постер, назву, опис, рік, жанр, режисера та рейтинг. Також містить кнопки додавання до обраного та Share.

screens/favorites_screen.dart
Екран зі списком обраних фільмів. Дозволяє переглядати додані фільми та видаляти їх зі списку.

### Папка test
У цій папці знаходяться Widget-тести, які перевіряють правильність роботи окремих компонентів інтерфейсу.

movie_search_bar_test.dart
Перевіряє роботу пошуку, кнопку очищення, індикатор завантаження та повідомлення No results.

movie_grid_test.dart
Перевіряє кількість колонок, відображення назви та рейтингу, заглушку постера і перехід до деталей фільму.

movie_detail_screen_test.dart
Перевіряє відображення інформації про фільм, зміну іконки обраного, неклікабельність рейтингу та наявність кнопки Share.

### Папка integration_test
app_test.dart
Містить інтеграційний тест, який перевіряє повний сценарій користувача: відкриття додатка, пошук фільму, перегляд деталей, додавання до обраного, перехід до Favorites та видалення фільму.

## Управління станом
Для управління станом використовується бібліотека Provider.
У проєкті застосовується ChangeNotifierProvider, який надає доступ до даних фільмів на різних екранах.


## Тестування
У проєкті реалізовано:
- 13 Widget-тестів - перевірка окремих компонентів інтерфейсу.
- 1 Integration-тест - перевірка повного сценарію роботи користувача.

Під час тестування використовуються такі Finders:
- find.byKey()
- find.text()
- find.byType()
- find.byIcon()

Також використовуються Matchers:
- findsOneWidget
- findsNothing
- findsNWidgets
